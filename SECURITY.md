# Security / 安全

Do not post tokens, settings files, personal paths or database dumps in public issues.
Report suspected credential exposure privately to the repository owner through GitHub private vulnerability
reporting when enabled. Rotate exposed credentials before sharing logs.

The optional PHP service must run behind HTTPS with a private writable data directory outside the web root.
Use your own strong random API token. Do not reuse the examples as production credentials.
Desktop API credentials are per-user settings, not a system keychain; protect access to your OS account.
